# 組合規劃與策略衝突整併

已實裝，預設版本 `silverfish-v1-combo-admission-v2`。本輪未啟動排位或呼叫付費模型。

## 修正的衝突

1. **同一武器路線由兩套程式各自推演。** 原本 combo-admission 與 weapon-buff 有不同的存活／未知效果條件。現在共同的有界搜尋產生 `lines`（完整組合證據）及 `weaponRoutes`（比較前綴）；weapon-buff 只讀這份證據做使用者三情況判斷，不再模擬第二個盤面。強制武器首步必須引用同一個 `proofKey`，而且首步仍在過濾後的合法候選中。
2. **通用搜尋拒絕，武器分支卻強制執行。** 真實第 18 場加上「召喚後觸發未知效果」的反例，能重現 v1 的強制武器分支；v2 不再強制。節點預算耗盡、候選首步被刪除、保守存活判斷不通過，也不能改走另一套推演繞過。隨機體質、未知嘲諷或未建模引擎不提供存活保證。
3. **有 buff 被誤當成已決定 buff。** `g4t7r616` 原本強制 Party→buff，遮住使用者標註的 Occultist→棄 Soul Barrage。現在保留可用指定棄牌路線比較；完整鋪場→buff 仍在選單。五怪／兩格情況中，魔眼自己占格會截掉侍僧召喚的裁定仍保留。
4. **資訊意圖與武器強制順序衝突。** 已選定的安全資訊意圖若保有整條組合費用，可先取得資訊，再觀察手牌重算。沒有把「可抽牌」當成「必須抽牌」。即時／確定搜尋斬殺仍先於資訊與鋪場。
5. **同一路線被重複命名為一般 PLAN、combo 和 wb。** 移除獨立 wb 選單；相同完整可執行序列保留 combo 表示。沒有 buff 費用或棄其他牌時，仍可用共同搜尋的 `development` 前綴比較；已有相同前綴的 PLAN 就沿用。秘密不確定的新增前綴只執行第一步並觀察，不快取推測的英雄攻擊。
6. **單步決策與自動對局走不同入口。** `decide.mjs` 改用與 bridge 相同的版本載入、候選證據、prepare、askJev 和 resolve。單步 CLI 仍只保存第一個動作，只有 bridge 負責實際接續及驗證。`eval-score` 的免費與模型路徑也傳遞裁剪前證據，避免先裁掉 buff 再重算組合造成證據消失。
7. **40 張開局合計 41 被漏掉。** `local-class-prior-v2` 在留牌階段將牌堆 36＋手牌 5 視為符合 40 張牌組加額外起手牌的推測訊號；紀錄明確寫「inferred／consistent with Coin」，沒有把隱藏牌當成已知。離開留牌階段不沿用當前數量推斷，30 張加幣與其他合計 41 不誤套。保存原批次四個公開數量快照（戰士／聖騎／牧師／法師），均能取得軟性先驗；依據既有控制／節奏／組合技／未知的局部頻率及信心調整留牌，沒有直接認定控制。這補上之前檢討漏列的聖騎開局，沒有改写舊對局或假稱重新校準模型準確率。

## 共用流程與紀錄

原始合法動作 → 有界發展證據 → 政策與安全篩選 → 確定斬殺 → 有優先依據的首步／完整意圖比較 → 執行 → 觀察。

武器比較的三情況維持：唯一棄侍僧且有 buff 費用；可棄侍僧但無 buff 費用；最高費是別張牌。裝備本身不觸發棄牌。費用、最高費目標、場位、戰鬥可信度與 buff 接續都來自同一條模擬前綴。通用搜尋仍有 256 邊／4 步預算；未完成證據回報截斷，不默默啟用另一個無預算分支。

紀錄新增 `decisionPolicy`、完整組合的 `weaponRouteKey`、比較前綴及被阻擋首步。PLAN 紀錄保存 `combination`／`developmentEvidence`。證據與比較前綴各最多向模型傳 12 條並標示截斷；完整內部搜尋仍供選單與政策使用。這些欄位協助區分「沒有證據」「被候選政策擋住」「強制規則選擇」「模型或備援選擇」，不代表策略正確率。

## Jev 策略文字整併

`decks/warlock-discard/strategy.md` 從 339 行、3523 個空白分隔詞整理為 159 行、1567 個詞。這是文字規模，不是模型 token 的量測。

移除互相矛盾的絕對指示：一定不要裸打棄牌素材、未斬殺的臉傷沒有價值、必須花光水晶、任何有效果手下都必須不計代價解、留牌勝率高就一定留，以及舊的已有三怪門檻。統一為存活／斬殺優先，選定資訊後再排序，完整發展與 buff 比較，依對手目標決定傷害與交換，並以早期曲線及一出口一素材校正留牌。

原始盤面、使用者案例與舊策略保留在既有 fixture、報告及 v1 固定來源中。策略縮寫沒有刪掉那些回溯資料。複雜未建模牌效仍保留完整文字供判斷。

新增 10 項組合回歸涵蓋同一證據引用、被刪首步、未知召喚引擎、預算耗盡、保守存活、先取得已選資訊、不完整武器路線、重複 PLAN、秘密後觀察、舊版固定來源，以及持有 buff 時的指定棄牌比較；另有 3 項開局訊號回歸。其中部分測試包含多個檢查，不等於新增 13 場對局。

7 個既有負面輸入仍沒有危險武器組合證據或跨未知結果的接續。42 個輸入含一個真實裁定與機制推導案例，參與開發驗證，不冒稱未見獨立測試。最終配對準備時間中位數為 v1 0.919 ms、v2 0.869 ms；同機並行評估，不能當成精確效能改善。大型歷史盤面主搜尋仍可耗時約 2.7 秒。

**最佳首步可選性增加不代表 Jev 一定選對。** `g4t7r616` 現在能比較正確指定棄牌路線，但離線備援仍可能選鋪場→buff；備援分未提高。策略文字的模型判斷效果、實際未知結果接續、執行成功率、對手推測準確率與勝率尚未經新版實戰驗證。
