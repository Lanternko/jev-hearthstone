# 對局目標：壓力時限與場面續航

使用者裁定：對控制，在有限回合內把牌與水晶轉成最大有效場面及傷害，錯過時限後難以靠直傷追回；對快攻／場面牌組，用有利交換、持續手下與補牌守住小幅領先，資源與公爵反超也是勝利路線。

已接入正式決策與回合搜尋，版本 `silverfish-v1-matchup-objective-v1`。這次確實調整搜尋評分，並加上對局依據與資源資訊供 Jev 評估；沒有訓練模型或進行 RL。

| 決策目標 | 壓力時限 pressure_window | 場面續航 board_resource |
|---|---|---|
| 勝利方向 | 在對手穩定／任務發力前，把場面轉成血量壓力 | 交換後保留手下與資源，維持主動權 |
| buff | 多體、同回合有效收益；避免沒有收益的單體 buff | 可用來改善交換／重奪場面，不強求每回合最大化 |
| 魔眼棄牌 | 可執行的鋪場與 buff 組合；不能假設任意素材都正確 | 鋪場、解場或必要資源依當前需求比較 |
| 抽牌／硬幣 | 要支持有價值的後續，核算失去的當前壓力 | 手牌少且安全領先時，允許比較補牌與 buff |
| 地標 | 付三費架設是否耽誤当前爆發必須評估 | 能透過正確棄牌素材補場並抽二時，有續航價值 |
| 公爵 | 依實際體質及可用費用評估 | 大體質＋Rush 有反超價值；不假設對方沒有單解 |

共通的可證斬殺、存活與可觀測卡效仍優先；有利交換對控制也可能保住下一輪攻擊，抽牌對控制也可能補到缺件，不能改成所有交換／抽牌都錯。第五／六回合不是硬編碼期限；「落後就輸」也不是對局結果標籤。

## 判斷對手與公開證據

Power parser 新增每局逐步累積的公開 PLAY 記錄與首回合公開初始生命，公開狀態只輸出已打出並揭露的牌。秘密只輸出格數，不暴露牌名；未打出的對手手牌／牌庫不輸出。換局清空，既有公開牌身分不被後來轉化改寫，跨回合晚揭露不回填為先前已知資訊；新公開證據也會改變決策指紋。

`matchup-objective.mjs` 依這些資料選目標：公開的指定任務時限，或有一致支持的 AOE＋抽牌／跳費／複製／40血跡象，偏壓力時限；前三回合強體質、持續出怪或強場面，偏場面續航。40血、職業、空過或事後完整分類都不單獨確定對局；矛盾證據維持 unknown。複製牧師公開複製＋AOE 可支持壓力時限，不因抄到我們的強怪就直接變快攻。精確發力回合未知，保留 `deadlineTurn: null`。

這是根據使用者判斷建立的公開證據規則，尚未量測其即時辨識準確率。現有歷史標註盘面多沒有完整逐步公開證據，不能拿它們的事後控制標籤直接灌入 live 狀態。

## 評分與規則改動

原有確定的戰鬥、場面價值、棄牌損失、生命與斬殺計算保留；依目標改變搜尋排序的粗略權重：

| 每單位權重 | unknown（原值） | 壓力時限 | 場面續航 |
|---|---:|---:|---:|
| 打臉傷害 | 0.6 | 1.1 | 0.3 |
| 對手總生命≤12時打臉 | 1.3 | 1.3 | 0.75 |
| 未知抽牌數 | 2.5 | 1.0 | 3.0 |
| 花費法力 | 0.5 | 0.8 | 0.5 |
| 失去硬幣的資源代價 | 0 | 0.8 | 0.3 |

數字是可檢驗的教練假說，未經訓練、未由勝率擬合。未知抽牌只計資源值，不產生虛構手牌；新目標計算法力時區分實際打出硬幣與棄掉硬幣，避免把新增法力當作免費收益。搜尋仍提供搶血、交換與抽牌不同方案給 Jev。

對場面對局，僅當非硬幣手牌≤2、至少兩隻存活手下、公開總攻擊及總剩餘血量領先、英雄有安全餘裕且牌庫未耗盡，解除「已有生產性 buff 就不能 Tap」的普遍封鎖。原本疲勞／自傷／過抽／致命線的安全篩選仍在；這只是允許比較，未強制為抽牌犧牲場面。有可證斬殺先斬殺。這個模式不套先前低壓開局的強制貪 buff，但仍保留多體路線供評估。

`resourceToolAssessments` 把手牌量、可補牌情境、地標可能素材／實際三選項與公爵當前 ATK／HEALTH／費用／格數送給 Jev。地標本體是「看三張手牌，棄一，抽二」，召喚零隻；只有棄牌收益素材實際入選並結算，才同時補場。公爵依當前 tags 讀體質，不捏造棄牌數；Rush 出場當回合不能直接打臉。武器是穩定 recurring 傷害來源，但套牌仍有 Soulfire 的指定傷害及 Soul Barrage 的隨機分配傷害，不能寫成只有武器會傷害。
