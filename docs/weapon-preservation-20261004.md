## 通則與實裝

- `src/weapon-preservation.mjs` 依卡文、最高費及並列候選、觀察體質、費用、場位、英雄攻擊資格與合法選項建立共用證據，復用 discardModel 與 discardGrowth。不把公爵的過去棄牌成長誤認成被棄收益。
- 裝備本身不棄牌。比較先打出高價值非收益手下與裝刀後攻擊的損失；記錄裝備後剩餘費用，以及先打手下、再裝備後的最高費候選。
- 對方空場、無秘密／未知友方事件引擎、離打臉斬殺仍遠，目標唯一且是已知單純體質收益，裝備會讓合法高價值手下不可支付時，優先先打手下。未知效果、同費並列、武器替換、必要解場與近斬殺保持比較。
- 高價值門檻是策略啟發式：攻擊至少為武器攻擊且至少 3，生命至少為武器攻擊且至少 4。沒有把 8/8 固定換算六七費，也不是校正過的勝率模型。
- 已裝備且剩零費，若只剩非斬殺打臉與結束，保留攻擊以保住手下。仍有其他合法打法就比較；免費抽牌／發現保留既有資訊優先判斷。
- 即時與搜尋斬殺優先。其他情境把證據附到 Jev 輸入與選項；bridge、單步 CLI 的正常及強制紀錄均保存 weaponPreservation。非斬殺排程動作也重新核對同一規則。
- 只選當前第一步，不排入下一回合、不跨未知抽牌。先打公爵、再装刀後目前最高費是 325，但下一回合抽牌可能加入更高費或同費牌，屆時必須重查。
