# 實驗登記（experiments）

訓練、評估、天梯批次、量測。讀寫規則見 [README.md](README.md)。
自戰模型各版本的長篇筆記（總表、每版設定與量測細節）保留在 [docs/selfplay-versions.md](../docs/selfplay-versions.md)；這裡的條目在「設定」欄寫版本名，可到該檔對應小節查細節。

欄位（固定）：
- **ID**：`E-001` 起，只追加。
- **日期**
- **假設**：要驗證什麼。
- **設定**：模型版本／模擬器版本／種子／局數／指令／機器。
- **結果**：數字（勝率附區間、局數）。
- **結論**
- **下一步**：沒有寫「無」。
- **相關**：其他 ID。
- **來源**（選填）

範例：

```
### E-999
- 日期：2026-10-27
- 假設：蛋階段進編碼後，zoo 從 v8 接續 150 輪能贏新蛋牧駕駛。
- 設定：5090，--seed 41 --stages，λ=0.1；selfplay-match.mjs 種子 1 貪婪 2000 局
- 結果：對蛋牧 P2 81.6%（79.8–83.2），v8 基準 79.0%
- 結論：過門檻，匯出 warlock-zoo-v9
- 下一步：實戰換 v9
- 相關：F-999
```

### E-004
- 日期：2026-09-20
- 假設：Jev 在有攻擊可打時選 END_TURN，是否因 END_TURN 機率主要由選項數決定、且逐選項 clock 能翻轉斬殺決策
- 設定：runtime/decisions.jsonl 全部 45 筆「同時有 END_TURN 與攻擊選項」的決策做統計；斬殺局面用 `src/experiment.mjs` 拿同一個 logged state 重問，換成逐選項 clock 後 4 次重跑
- 結果：`P(END_TURN)` 幾乎貼著 1/n（n=選項數），倍數中位數 0.72；斬殺那手 n=6、P(o0)=0.55，為 1/n 的 3.30 倍（次高僅 1.32）。

  |---|---|---|---|
  | 舊：同一句 clock 貼在所有選項 | 0.55 | 0.23 | o0 放棄勝利 |
  | 新：逐選項 clock | 0.07–0.08 | 0.71–0.75 | o1t0 |
- 結論：END_TURN 的機率主要由選項數決定，不是由「結束回合有多糟」決定；回合選項數單調遞減，回合尾聲 n=2~4 時 END_TURN 機率自動升到 0.25~0.5，解釋了「打到一半放棄剩餘攻擊」。先前「補事實無法讓 Jev 把已成立的勝利執行完、跨選項執行必須人工覆寫」的結論作廢，那是我們自己的描述缺陷造成的假象
- 下一步：無（`src/lethal.mjs` 的強制斬殺保留：0.72 不是 1.0，斬殺有唯一正解，沒有理由對勝利擲骰子）
