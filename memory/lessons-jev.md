### L-002 送進模型的事實要有區辨力
- 日期：2026-09-20～2026-09-21
- 發生什麼：clock 句子在所有選項上一字不差，對逐選項評分器零區辨力；初版結論「連結論都餵了還是沒用」下得太滿，實驗根本沒測到要測的東西。常數標籤同樣無效。
- 規則：評估模型之前，先確認送進去的事實對各選項有區辨力；在整個選項集上為常數的句子或標籤不能拿來推論模型能力，標籤只在有差異處寫進選項。
- 對應測試或關卡：無（後續有「clock 在各選項上不得相同」測試，見 f52）
- 相關：E-004、F-014、F-024
- 合併自：L-002、L-004、L-006
- 來源：archive/STATUS-2026-10-27.md 第 2051、1996、2198 行

### L-016 凍結的版本來源
- 日期：2026-10-02
- 發生什麼：新版引擎與舊版共用資料名稱，舊版結果會被新版來源污染；baseline 副本放在 npm test 掃描的路徑，全套誤載入副本而失敗。
- 規則：每個版本標籤對應其修改前凍結的來源，舊版改讀凍結來源；凍結／基準副本以 ZIP 保存，放在測試掃描路徑外。
- 對應測試或關卡：npm test（重跑通過）
- 相關：F-262、F-267
- 合併自：L-016、L-017
- 來源：archive/STATUS-2026-10-27.md 第 2541、2553 行
